# Dora Machines哆啦科技

### This addon add:
- pickaxe and shovel that can break 5x5x5 or 3x3x3 area blocks at once
- filter base which can filter some dust when it's waterlogged
- industrial miner like slimefun's industrial miner
- unbreakable rune
- etc.

### 本附属添加了：
- 可以一次性破坏5x5x5或3x3x3区域镐子和铲子
- 可以在含水状态下滤出各种粉尘的滤网
- 和粘液科技相似的工业矿机
- 不可破坏符文
- 等等。。。
